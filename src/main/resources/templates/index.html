Essbase Java API Evolution

Changes to classes, interfaces, methods, and more in the Essbase Java API over time

Reading this report

Each version below lists what changed in the Essbase Java API relative to the version before it, in four categories: added, modified, removed, and deprecated. The added category lists classes and interfaces that were not present in the previous version of the jar, along with their public methods, which are new by definition. The modified category lists types that changed in some way, typically because a method was added, removed, or had its arguments or return type changed. The removed category lists types that are gone. The deprecated category lists methods that gained the deprecated annotation.

Note that the change analyzer lists both base classes (such as EssCube) as well as the more commonly used interface object for the corresponding class (such as IEssCube). Typically in the Essbase Java API, all operations are performed with interfaces. While you typically shouldn't program with the base classes, they are in fact public and are occasionally used.

New methods appear in green, removed methods are in red, deprecated are marked with strike-through. A version that changed no public API says so.
